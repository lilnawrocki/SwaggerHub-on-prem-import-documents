## Description

This application can automatically publish Swagger documents (APIs, domains, templates) to SwaggerHub on-premise instance, that were previously downloaded using https://github.com/lilnawrocki/SwaggerHub-on-prem-download-APIs

The application asks the user for admin API key and host. It expects the `SwaggerHub-Downloads` directory to be present inside the project directory. The application imports YAML documents without integrations.
